# 菜单研究：结构、入口与修订

范围：Z9原5.32 MAIN SHA `6380ded18395ce11cb327c766721274c85127d2cf1a1e887ee60e3d156810bdd`。当前可选f2变体源码来源提交a519d73；文档不含厂商反编译正文、菜单表正文或原厂二进制。数值合同和新增源码供定位消费者使用，跨机型须重证。

## 从显示到执行的分层

菜单定义/文字 → 有界事件表 → 原提交/属性批处理 → 调用队列与worker → 原生类别/Quick → 实际图像生产 → 退出/恢复 → 持久化。任一层通过都不替代下一层；右侧显示C30不代表原生Quick或实际照片模式已经改变。

### 页面与表结构

| 对象 | 当前Z9合同 | 新增方式 / 源码 |
|---|---|---|
| 普通/保持父页 | 原页面0x225，共用上下文A02909790 | 原12项位置保留，增加VR行，保存当前设定由行12移到13，总14行 |
| 父页holder | 初始化RAM A028C2970 | +16行指针、+24事件指针数组、+32为16位行数 |
| 释放页 | 原页面0x235，上下文A02909D90；holder A028C2E70 | CH/CL/S原3行保留，追加C15/C30，总5行 |
| CH/CL速度子页 | 原状态0x236/0x237 | 保留原提交，只有原接受后才清除私有Cxx覆盖 |
| VR叶子 | slot2、局部ID0x6C6，动态创建 | `f2r_menu_lookup`校验slot、上页与拥有关系，不把局部ID当全局可占用ID |

原行44字节、事件记录32字节、页面state96字节、holder80字节、callback40字节。VR原生标题/释放页模板头544字节，不能由一个行数推断整页模板大小。菜单事件以0x3CA终止：原父页普通表22条、保存表21条、释放表16条；VR叶子使用另一份15条模板。历史固定读取32条会跨邻表，已撤回该做法。

`tools/recall_menu_patch.py`从用户精确原模块提取模板，保留原事件条件，仅替换有边界的callback。事件0x298/0x29D/0x2C0等由消费者判定；不能把它们不加版本说明地解释成某个实体按键。提交event结构24字节，context在+0、target在+12；刷新函数直接收context，二者ABI不同。

### 文字、图标、勾选与焦点

新VR UI为0x7EA0，C15/C30为0x7EA1/0x7EA2；VR详情Off/Normal/Sport使用0x7EA3+i。这些是UI编号，不是DSID、标签ID或页ID。右值widget0x4BEC的kind1为图标、kind2为翻译文字；原对象类型不匹配时先按原接口复位再写kind2，不能只替换label。

原勾选帮助函数的参数是cache-index0x81..0x8C，不是UI ID；扩展没有借用一个未经证明的“空槽”。行位置由context的两个16位索引（+0x32/+0x58）相加；定义中的隐藏说明行使表索引差不等于拨盘/方向键次数。调试时先核实实际页面，再逐步移动焦点。

## 重要历史修订

- 060014E4/06007936、06000674及相关转换是AF区域数据，不是释放模式。
- 原释放目标S0/CL1/CH2与Quick C15=6/C30=3分属不同编号空间。早期直接在目标getter输出6/3的方案已由P684修正：目标输出CH2，再在原门槛之后选择Quick。
- 一次MENU返回失败或主机读取地址笔误不能当作固件UI失败；setter返回或调用入队也不能当作worker已执行。
- 0x00001C26可能保留旧HSFC选择；不能仅凭它判定当前S/C15/C30。联合selector、类别、Quick/latch、活动条件和实际照片验证。
