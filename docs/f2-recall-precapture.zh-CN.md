# f2/Fn1 与预拍摄菜单扩展

这是在原v39上新增的**可选源码变体**，入口为 `variants/f2-recall/tools/build.py`。根目录原v39源码、旧手册及原构建入口保持历史身份。新变体整合mark1防抖按键和两类“重新调用拍摄功能”的防抖、C15/C30选项，继续使用v39预拍摄设置。

## 使用与编号合同

- 自定义设定f2 → Fn1（或其他原生支持调用的按键）→“重新调用拍摄功能”或“重新调用拍摄功能（保持）”。两列分别选择和保存防抖及释放覆盖。
- 防抖沿用关闭/标准/运动语义；普通与保持列相互独立，不改变另一列原有选项。
- 释放选项保留原生模式，增加C15/C30。菜单值、私有编码与原生Quick/latch是不同编号空间。
- 本变体已验证的Fn1保持列1：C15为原生连续类别1、Quick/latch6；C30为连续类别1、Quick/latch3。不能套用实体拨盘测试的旧mode标签。
- 普通S格式与高速预拍摄格式分别设置。原版C30不支持RAW；v39的RAW预拍摄使用HE/HE★，不支持Lossless。
- 切回S必须让原生历史、解码、JPEG和候选帧槽位实际退役。QEMU中的等待条件是验证工具约束，不是新增固件菜单，也不是固定等待秒数。

## 可重复构建

需要Python3、AArch64 GCC13.3.0/binutils2.42及用户自己提供的精确原5.32模块。输出必须在仓库外且保持私有：

```sh
python3 -B tests/f2_recall.py --output /private/new-recall-tests
python3 -B variants/f2-recall/tools/build.py --module /private/eg1990_053200.bi --output /private/new-f2-build --version 5.61
```

支持5.32、5.60、5.61开发标签，业务基础均为原5.32。5.61只是本菜单基线的版本标识，不代表官方5.61源码。MAIN完整SHA由变体profile.json严格检查；5.61应为 `2234ed4905dbe875cdba1269d91b61e6a53585a4088463dd0d8e6cc419b04670`。

菜单原结构由配方从精确原模块提取；新增标签从自编写UTF16文字生成。不依赖本地历史mark1固件或内部目录，不公开完整固件、原菜单表、私有封包材料、实拍照片或个人WAV。原目录既有截图/PDF的来源与权属说明不变，此次没有增加图片。
